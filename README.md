# RockingMan PiCar-Pro Companion Robot

Personal robotics development layer for the Adeept PiCar-Pro V2.0,
running on a Raspberry Pi 5.

This repository contains custom experiments and robot functionality.
The official Adeept PiCar-Pro repository is kept separately as the
vendor hardware/software dependency.

## Current modules

- arm calibration and motion experiments
- smooth multi-servo trajectory control
- OLED status and battery monitoring
- Xbox controller driving
- UDP remote-control experiments
- demonstration/show sequences
- robot shutdown behaviour

## Vendor dependency

Official Adeept software is currently expected at:

~/Adeept_PiCar-Pro

This dependency boundary will be cleaned up as the project evolves.
